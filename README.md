# AURA — база программ и трекер заявок

MVP образовательной платформы для самостоятельного поступления за рубеж на гранты.
Дизайн — [Figma AURA01](https://www.figma.com/design/Fz0b5mE2fDTU3igLv9Lom8/AURA01).

## Что внутри

| Маршрут | Экран |
|---|---|
| `#/` | Лендинг: hero, трекер, полоса доверия, «Что умеет AURA», «Как это работает», тизер каталога, гайды |
| `#/catalog` | Каталог 18 стран с поиском и фильтрами (степень, полный грант) |
| `#/country/:id` | Страница страны: полный разбор для `korea` и `turkey`, общий шаблон для остальных |
| `#/guides`, `#/guides/:slug` | Гайды: эссе, рекомендательное письмо, Common App |
| `#/register`, `#/login` | Регистрация/вход (email + пароль или «Google» — мок) |
| `#/onboarding` | Квиз: степень, этап, финансирование, баллы |
| `#/dashboard` | Кабинет: прогресс, этапы, мои программы с чек-листом документов, дедлайны, рекомендации |

Бэкенда нет: пользователи, анкета и трекер хранятся в `localStorage` браузера.
Это демо — пароли не защищены, не используйте настоящие.

## Запуск

```bash
npm install
npm run dev
```

## Где править контент

- `src/data/countries.ts` — страны, гранты, пороги IELTS/GPA, дедлайны, ссылки, документы. Места с `TODO` нужно сверить с первоисточниками.
- `src/data/countryDetails/*.ts` — полные разборы стран.
- `src/data/guides/*.ts` — гайды. Контент описывается блоками (`src/data/types.ts`), один рендерер на всё.

## Деплой на GitHub Pages (бесплатно)

1. Создайте публичный репозиторий на GitHub и запушьте в ветку `main`.
2. В репозитории: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
3. Каждый push в `main` собирает сайт (`.github/workflows/deploy.yml`) и публикует его по адресу
   `https://<username>.github.io/<repo>/`.

Роутинг на хэшах (`#/catalog`), поэтому прямые ссылки работают без настройки сервера.
